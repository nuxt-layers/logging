# Storage register

Process-local diagnostic history: bounded trusted tenant/source, codes, opaque correlation, numeric/boolean fields and timestamps; delivery states and local restriction flag. Purpose technical diagnostics. Host-configured retention at most 30 days, lazy expiry and process termination. No durable storage, cookies or browser storage. Protected local export discloses only scoped sanitised records; local erasure/restriction do not alter provider data. Independent approval references returned, not retained by Logging. Host local/external sinks independently document location, retention, access, holds, deletion and backups. Rate buckets and global health counters are process-local. Cache is not legal preservation custody; durable hold, provider rights and lifecycle evidence remain unavailable. Do not deploy for workloads requiring them.

Optional Logging-owned SQLite journal: persistent restriction/erasure tombstones, scoped request fingerprints, outbox events with opaque subject/evidence references and acknowledgement flag. WAL and backups contain the same sensitive operational metadata. Host selects secured file location, permissions and backup controls. No automated retention or compaction yet; do not deploy unbounded journal for regulated workloads without approved retention. No diagnostic payload persisted by this adapter.

Optional diagnostic store persists sanitised records and delivery state in the same database. Capacity max 10000. Expiry hides aged records; explicit verified-clock maintenance with clear preservation removes local payloads only. Held/unknown retained. WAL/backups require separate controls. Journal retention still outstanding.

Purpose-specific retention ceilings are recorded on admission; current policy may shorten but not extend the admitted lifetime. Maintenance uses bounded rotating scans and does not delete held/unknown payloads.

Optional governed journal maintenance deletes only aged, acknowledged outbox event payloads with verified acknowledgement time and independent preservation clearance. Pending/unknown/held events, request identities and restriction/erasure markers remain retained. Database pages, WAL and backup disposal are separate host obligations.

SQLite journal metadata capacity defaults to 100000 rows per category (request identities, markers, and events plus reserved event slots), configurable 1–1000000. Existing over-limit data is preserved. Durable external reservations hold scoped identifiers, operation kind and target or policy revisions; pending reservations survive restarts. No automated retirement. Capacity exhaustion blocks new protected work rather than discarding evidence. Physical file/WAL/backup bounds remain host obligations.
